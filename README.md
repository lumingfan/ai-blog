

# 项目简介

AI-Flux 是一个基于 Vue 3 + TypeScript 技术栈开发的现代化博客平台，集成了 AI 对话、技术文章创作与分享等功能。本项目旨在通过实际业务场景的开发实践，提升 Java 全栈开发技术能力，深化对现代 Web 开发技术栈的理解与应用。

# 项目背景

随着人工智能技术的快速发展和内容创作需求的不断增长，传统博客平台已无法满足用户对智能化、个性化内容创作的需求。AI-Flux 项目应运而生，致力于打造一个集智能对话、内容创作、知识分享于一体的综合性平台。

项目采用前后端分离架构，前端使用 Vue 3 生态系统，后端基于 Spring Boot 微服务架构，通过实际开发过程锻炼业务编码能力、中间件集成能力以及文档阅读学习能力。

# 核心技术栈

### 前端技术

- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **UI 组件库**: Element Plus
- **状态管理**: Pinia
- **路由管理**: Vue Router
- **编辑器**: Vditor (Markdown 编辑器)
- **样式**: SCSS

```txt
src/
├── api/           # API 接口层
├── assets/        # 静态资源
├── components/    # 可复用组件
├── constants/     # 常量定义
├── router/        # 路由配置
├── service/       # 服务层
├── stores/        # Pinia 状态管理
├── styles/        # 全局样式
├── types/         # TypeScript 类型定义
├── utils/         # 工具函数
├── views/         # 页面组件
└── main.ts        # 应用入口
```

### 后端技术
- 核心框架: Java + Spring + SpringBoot + SpringAI 
- 数据层: MySQL + Redis + MybatisPlus
- 消息队列: RocketMQ
- 安全认证: Sa-Token
- 实时通信: WebSocket
- 工具库: Hutool, Jackson, Knife4j, Log4j2, Minio, COS



### 开发工具

- **代码规范**: ESLint + Prettier
- **Git 提交规范**: Commitlint + Husky
- **包管理**: pnpm
